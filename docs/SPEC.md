# ERuDict — постановка задачи

Фоновый англо-русский переводчик выделенного текста для Windows.

**ERuDict** = English–Russian Dictionary.

## 1. Цель

Легковесное приложение для Windows, работающее в фоне (системный трей). По горячей клавише (по умолчанию — двойное нажатие Ctrl) переводит выделенный в любом приложении текст через Яндекс или Google Translate и показывает результат во всплывающем окне возле курсора.

## 2. Технологии

- Язык: **C#**
- Платформа: **.NET 8**, UI — WinForms (без внешних NuGet-зависимостей)
- Сборка: самодостаточный один `exe` (`win-x64`, self-contained, single-file)
- Сеть: бесплатные неофициальные endpoint'ы Яндекс.Переводчика и Google Translate, без API-ключа
- Интерфейс: русский и английский

## 3. Функциональные требования

### 3.1 Системный трей

- Иконка приложения в трее.
- Контекстное меню: «Перевести выделенное», «Настройки», «Помощь», «Выход» (и английские эквиваленты).
- Tooltip у иконки с названием и кратким описанием.
- Повторный запуск не создаёт второй экземпляр: показывается сообщение на языке интерфейса.

### 3.2 Горячая клавиша

- По умолчанию: **двойное нажатие Ctrl** (интервал по умолчанию 400 мс).
- Реализация: низкоуровневый глобальный хук (`WH_KEYBOARD_LL`). Клавиши не блокируются.
- Альтернатива в настройках: `Ctrl+Shift`.

### 3.3 Получение выделенного текста

- Сохранить Unicode-текст буфера, эмулировать `Ctrl+C` (`SendInput`), прочитать `CF_UNICODETEXT`, восстановить буфер.
- Не клонировать OLE/RTF/HTML (защита от падений Outlook и других rich-text приложений).
- Пустое выделение — ничего не делать. Лимит: 5000 символов.

### 3.4 Перевод

- Сервисы: Яндекс, Google, либо **Авто** (Яндекс, при ошибке Google).
- Направление:
  - ≥80% латинских букв → английский → язык перевода из настроек (обычно `ru`);
  - ≥80% кириллицы → русский (или домашний кириллический) → английский;
  - иначе `auto` → язык из настроек.
- Таймаут HTTP — 10 секунд. Если оба онлайн-сервиса недоступны — офлайн-словарь FreeDict (по словам, максимум 15), с ремаркой для пользователя.

### 3.5 Отображение результата

- Короткое выделение (1–3 слова): мини-тултип только с переводом и кнопкой «Развернуть».
- Более длинный текст: попап с исходником и переводом, направление и имя сервиса.
- Закрытие: Esc, клик по рамке, таймаут. Опция копирования перевода в буфер.

### 3.6 Язык интерфейса

- Языки UI: русский и английский.
- По умолчанию: **системная локаль**. Если UI Windows — русский (`ru`), интерфейс русский; иначе английский.
- Выбор в настройках: системный / Русский / English. Применяется сразу, без перезапуска.

### 3.7 Настройки

Файл `appsettings.json` рядом с exe:

| Поле | Описание | По умолчанию |
|---|---|---|
| `uiLanguage` | `auto` / `ru` / `en` | `auto` |
| `targetLanguage` | Код языка перевода | `ru` при системном `ru`, иначе `en` |
| `translator` | `auto` / `yandex` / `google` | `auto` |
| `doublePressIntervalMs` | Интервал двойного Ctrl | `400` |
| `popupTimeoutSec` | Автоскрытие (0 — не скрывать) | `8` |
| `copyToClipboard` | Копировать перевод | `false` |
| `hotkeyMode` | `doubleCtrl` / `ctrlShift` | `doubleCtrl` |
| `startWithWindows` | Автозагрузка | `false` |
| `autoDetectDirection` | Автонаправление по алфавиту | `true` |

### 3.8 Помощь

Пункт «Помощь» / Help в меню трея открывает окно с инструкцией на текущем языке интерфейса. Полный текст также лежит в `docs/USAGE.md`.

## 4. Нефункциональные требования

- Низкое потребление CPU/памяти в фоне.
- Запуск без установки: один self-contained exe.
- Автозагрузка через `HKCU\...\Run` (`ERuDict`).
- Лог: `erudict.log` рядом с exe (не во временной папке single-file).
- Интерфейс на русском или английском.

## 5. Архитектура

| Модуль | Ответственность |
|---|---|
| `Program` | Точка входа, один экземпляр, язык UI |
| `I18n` | Строки интерфейса ru/en |
| `TrayApp` | Трей, меню, оркестрация |
| `HotkeyManager` | Хук клавиатуры |
| `ClipboardManager` / `NativeClipboard` | Захват выделения |
| `Translator` | Выбор сервиса |
| `YandexTranslator` / `GoogleTranslator` | HTTP-клиенты |
| `LanguageDetector` | Направление EN↔RU |
| `PopupWindow` / `MiniTooltipWindow` | Окна результата |
| `Settings` / `SettingsDialog` | Настройки |
| `HelpDialog` | Справка |

Поток:

```
двойной Ctrl
  → HotkeyManager
  → ClipboardManager
  → LanguageDetector
  → Translator (Yandex / Google)
  → MiniTooltip (≤3 слова) или PopupWindow
```

## 6. Сборка

```sh
dotnet publish -c Release -p:PublishProfile=Win64SelfContained
```

Результат: `bin/Release/publish/ERuDict.exe`.
